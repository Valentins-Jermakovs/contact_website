About

I learned to build software on my own, and I focus on the part users never see: the services, data and access rules behind an application.

I write in Python and JavaScript. I build APIs with FastAPI, keep data in PostgreSQL, and use Redis where a fast store helps. I run my own services on Linux and package them with Docker.

I am interested in backend architecture and open source, and I run language models locally.
